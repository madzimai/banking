# banking
#🏦  Java Banking Management System

A beginner-to-intermediate Java project built step-by-step while learning Object-Oriented Programming, Collections, and backend development concepts.

This project simulates a simple banking system where users can create accounts, deposit money, withdraw money, search accounts, and transfer funds.

🚀 Learning Journey (Day 1 – Day 9)

This project was built progressively while learning Java concepts in public.

📘 Day 1 – BankAccount Class (OOP Basics)

- Created the BankAccount class
- Learned about objects and fields
- Introduced encapsulation
📘 Day 2 – Constructors

- Initialized objects using constructors
- Used this keyword
- Created structured object creation

📘 Day 3 – Deposit Feature
- Added deposit() method
- Learned method parameters
- Applied validation rules

📘 Day 4 – Withdraw Feature

📘 Day 5 – Display Account Details

📘 Day 7 – Search Account Feature
- Built findAccount() method
- Learned object searching in collections

- Combined all features together
